# Personal Expense Tracker

## Purpose
Record income and expenses and review spending by category.

## Features
- Record income and expenses with dates.
- View all transactions and financial summaries.
- Calculate spending by category.
- Search by description or category and warn when expenses exceed income.

## Requirements
- Python 3.10 or later
- No third-party packages required

## How to run
1. Open a terminal in this project folder.
2. Run `python main.py`.
3. Follow the on-screen menu.
